# جام پیش‌بینی ۲۰۲۶ ⚽🏆

سایت پیش‌بینی دوستانهٔ بازی‌های مرحلهٔ گروهی جام جهانی فیفا ۲۰۲۶ (آمریکا · کانادا · مکزیک).
بدون هیچ وابستگیِ خارجی — فقط Node.js نصب باشد کافی است.

---

## ⚙️ راه‌اندازی روی سیستم خودت

نیازمندی: **Node.js نسخهٔ ۱۸ یا بالاتر**.

```bash
node server.js
```

سپس مرورگر را باز کن: <http://localhost:3000>

برای تغییر پورت:

```bash
PORT=8080 node server.js
```

---

## ☁️ گذاشتن روی هاست

این یک اپلیکیشن **Node.js** است (نه فقط HTML ساده)، چون باید پیش‌بینی‌های همهٔ دوستان روی سرور
ذخیره و بین همه به اشتراک گذاشته شود و قفلِ زمان شروع هم سمت سرور اعمال شود.

روی هر هاستی که Node اجرا می‌کند کار می‌کند:

- **سرور مجازی / VPS:** فایل‌ها را آپلود کن و برای پایداری از pm2 استفاده کن:
  ```bash
  npm install -g pm2
  pm2 start server.js --name wc2026
  pm2 save
  ```
  بهتر است پشت Nginx با HTTPS قرار بگیرد.
- **Render / Railway / Fly.io و مشابه:** دستور اجرا را `node server.js` بگذار و مقدار `PORT` را
  از متغیر محیطیِ خودِ سرویس بخوان (همین حالا پشتیبانی می‌شود).
- **هاست اشتراکی فقط-استاتیک (مثل GitHub Pages):** کار **نمی‌کند**، چون به اجرای Node و ذخیرهٔ
  مشترک نیاز داریم.

دوستانت فقط کافی است آدرس هاست تو را در مرورگر باز کنند و اسمشان را وارد کنند.

---

## 🗂️ ساختار فایل‌ها

```
server.js          سرور بدون وابستگی + API + اعمال قفل سمت سرور
data.json          داده‌ها (کاربرها، پیش‌بینی‌ها، نتایج) — خودکار ساخته می‌شود
package.json
public/
  index.html
  styles.css
  app.js           رابط کاربری (بدون فریم‌ورک)
  shared.js        تیم‌ها، ۷۲ بازی، موتور امتیازدهی و منطق قفل (مشترک سرور و مرورگر)
test.js            تست کامل (واحد + شبیه‌سازی ۳۰ کاربر روی سرور واقعی)
```

⚠️ **پشتیبان بگیر:** همهٔ اطلاعات در `data.json` است. برای پاک کردن کل بازی، این فایل را حذف کن.

## 🎮 نحوهٔ کار

- **اولین کسی که وارد می‌شود «مدیر» می‌شود** و در تب «مدیریت» نتایج واقعی هر بازی را وارد می‌کند
  (می‌تواند نقش مدیر را به دیگری بدهد). بقیه فقط پیش‌بینی می‌کنند.
- **قفل:** هر بازی **دقیقاً سرِ زمان سوت شروع** قفل می‌شود و پس از آن نه از طریق صفحه و نه از طریق
  API قابل تغییر نیست (قفل سمت سرور است و قابل دور زدن نیست).
- زمان‌ها بر اساس ساعت محلیِ خودِ مرورگر هر کاربر نمایش داده می‌شوند.

## 🧮 سیستم امتیازدهی (در تب «مدیریت» قابل تغییر)

| مورد | امتیاز پیش‌فرض |
| --- | --- |
| پیش‌بینی درست برد / مساوی / باخت | ۳ |
| تعداد گل یکی از دو تیم درست | ۲ |
| نتیجهٔ کاملاً دقیق (هر دو تیم) | ۵ |
| هر گلزن درست (حداکثر ۲ نفر) | ۲ هرکدام |

نتیجهٔ کاملاً دقیق + هر دو گلزن درست = حداکثر **۱۲ امتیاز** در هر بازی.
